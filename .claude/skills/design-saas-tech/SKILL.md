# SaaS, Tech & IT Services

**Audience**: buyers and evaluators who skim for *what it does, who it's for, proof (logos/metrics), and how to start*. Higher tolerance for detail, low tolerance for vagueness.
**Primary conversion**: Book a demo / Start free trial / Get an IT assessment · secondary: See pricing / how it works.

## Pick one direction
**A. Precise Product** (default)
- paper `#ffffff`, surface `#f6f7f9`, ink `#0a0d14`, muted `#525a6a`, line `#e6e8ee`, brand `#0a0d14`, brand-ink `#fff`, accent `#4f46e5` → only if brand is indigo; otherwise use the client's brand hue saturated (accent-ink `#fff`), deep `#0a0d14`.
- Fonts: **Geist** or **Inter** display (600, tight tracking) + same body; mono labels with system mono. Product UI screenshots in framed "window" cards, bento grid for features, crisp 1px borders.
**B. Dark Technical** (security, dev tools, infrastructure)
- paper `#07090d`, surface `#0f131a`, ink `#e8ebf1`, muted `#9aa3b2`, line `#1d232d`, brand `#e8ebf1`, brand-ink `#07090d`, accent `#22d3ee` (accent-ink `#04161a`), deep `#000`. Fonts **Space Grotesk** + **Inter**. Subtle grid/dot backgrounds, glow used once.
**C. Friendly IT Partner** (local MSPs, IT support)
- paper `#ffffff`, surface `#f1f6fb`, ink `#0e1b2b`, brand `#123b69`, accent `#16a34a` (accent-ink `#fff`), deep `#0b2440`. Fonts **Plus Jakarta Sans** + **Inter**. Human team photos, response-time promises.

## Homepage order
Header (Login, Book demo) → Hero (H1 = outcome for a named audience, subhead = how, CTAs, product visual or IT team photo, proof: customer logos / uptime / response time) → Logo wall → Problem → solution (3 pains, 3 fixes) → Feature bento (4–6 tiles) → How it works (3 steps) → Metrics/case study (real) → Integrations/stack or service plans → Testimonials → Pricing teaser or plans → FAQ (security, onboarding, contracts) → CTA band → Footer (product/company/legal columns).

## Avoid
Purple-blue gradient mesh hero, vague "revolutionize" copy, 12-feature walls, fake dashboards with lorem numbers, robot/brain stock art.
